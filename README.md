# Dawami | دَوّامي

تطبيق عربي RTL لإدارة الحضور والرواتب والإجازات للشركات والموظفين.

## تشغيل المشروع

ثبّت الاعتمادات باستخدام `pnpm install`، ثم جهّز متغيرات البيئة من `.env.example`، وبعدها شغّل بيئة التطوير باستخدام `pnpm dev`. لفحص الأنواع والاختبارات استخدم `pnpm check` و`pnpm test`، ولإنشاء نسخة الإنتاج استخدم `pnpm build`.

## تسجيل الدخول

يستطيع المدير إنشاء حساب محلي من شاشة الدخول باستخدام اسم مستخدم وكلمة مرور، دون الحاجة إلى بريد إلكتروني. تُخزّن كلمات المرور بتشفير scrypt ولا تُرسل إلى الواجهة. يبقى تسجيل الدخول عبر Google/Manus OAuth متاحًا كخيار بديل، بينما يدخل الموظف من خلال رابط أو QR مخصص ينقله إلى مسار حسابه الأساسي. لا تستخدم روابط `demo` إلا لمراجعة الواجهة والاختبار.

## الأدوار والبيانات

يصل المدير إلى إعدادات الشركة والموظفين والحضور والإجازات والرواتب والتقارير. يستطيع الموظف تسجيل الحضور بعد التحقق من موقع العمل، بدء الاستراحة وإنهائها، إرسال طلب إجازة، ومراجعة سجله وراتبه المتوقع. يحفظ النظام البيانات في قاعدة البيانات ويستخدم التخزين الزمني بصيغة UTC في طبقة الخادم.

## QR الموظف

ينشئ المدير كود دخول وQR مخصصًا لكل موظف من لوحة الموظفين. يمسح الموظف QR من هاتفه، ثم يتابع تسجيل الدخول بالحساب المرتبط به؛ لا يُستخدم QR كبديل عن جلسة المصادقة ولا يمنح المدير صلاحية تسجيل الحضور نيابة عن الموظف.

## قواعد الرواتب

يدعم التطبيق أجر ساعة مستقلًا لكل موظف، عملة الشركة، وقواعد الساعات الشهرية القابلة للضبط: 192 ساعة لشهر من 28 يومًا، و208 لشهر من 30 يومًا، و216 لشهر من 31 يومًا. يستطيع المدير تحديد بداية عيد الفطر وعيد الأضحى، ويطبّق النظام إضافة 8 ساعات في اليوم الأول ومعامل 1.5 على الحضور الفعلي في الأيام التالية.

## تصدير التقارير

تتضمن لوحة المدير تنزيل كشف الرواتب والتقرير الشهري بصيغتي CSV وExcel XLSX. لا تحتوي ملفات المشروع على أسرار؛ ضع القيم الخاصة بالبيئة محليًا أو في إعدادات الاستضافة ولا ترفع ملف `.env` إلى GitHub.

## GitHub والنشر

لرفع المشروع إلى مستودع خاص استخدم من داخل مجلد المشروع: `git init` ثم `git add .` و`git commit -m "Dawami Core"`، وبعد إنشاء مستودع خاص اربطه بالأمر `git remote add origin <REPOSITORY_URL>` ثم نفّذ `git push -u origin main`. يمكن تنزيل ملفات النسخة من رابط المشروع المرفق في رسالة التسليم أو استخدام مستودع GitHub الخاص. GitHub Pages وحده لا يشغّل خادم Node.js أو قاعدة MySQL؛ استخدم خدمة استضافة تدعم Node.js وقاعدة MySQL، ثم اضبط أمر البناء `pnpm build` وأمر التشغيل `pnpm start`.

قبل التشغيل، يجب توفير متغيرات البيئة التي يطلبها قالب Manus، ومنها `DATABASE_URL` و`JWT_SECRET` وإعدادات OAuth. لا ترفع `.env` أو أي مفاتيح API أو بيانات اتصال إلى GitHub. استخدم أسرار إعدادات الاستضافة بدلًا من تخزينها في الملفات.

للمراجعة قبل النشر، نفّذ `pnpm install` ثم `pnpm check && pnpm test && pnpm build`. بعد نجاحها شغّل `pnpm start` في بيئة الإنتاج أو `pnpm dev` للتطوير المحلي.
